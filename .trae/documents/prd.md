## 1. 产品概述

跨海大桥结构健康监测（SHM）数字孪生底座——基于 Three.js WebGL 与 Node.js WebSocket 的高保真桥梁数字孪生系统。通过参数化 3D 骨架实时还原悬索桥空间结构，并以 GPU 侧色谱映射技术将 50Hz 光纤 Bragg 光栅（FBG）应变数据流可视化映射至吊索三维模型，实现从物理传感器到数字模型的全链路实时张力感知。

- 面向桥梁工程监测人员与结构安全决策者，解决传统监测系统数据与空间模型割裂、无法直觉感知结构受力的痛点
- 核心价值：毫秒级应变数据驱动的三维张力色谱可视化，将抽象微应变数值转化为直觉可辨的冷绿→亮红色谱过渡

## 3. 核心流程

1. 后端启动 WebSocket 服务，模拟 50Hz FBG 传感器数据推流
2. 前端建立 WebSocket 连接，接收微应变数据包
3. 数据分发至各吊索对应的 ShaderMaterial Uniform 变量
4. GPU 每帧根据 Uniform 值插值计算吊索顶点颜色（冷绿→亮红）
5. 监测人员在 3D 场景中实时观察张力分布变化

### 4.4 3D 场景引导

- **环境**：深空黑背景 + 微弱星空粒子，低饱和度雾化增加纵深感
- **光照**：DirectionalLight 主光（偏冷白），AmbientLight 微弱填充，PointLight 置于主塔顶部模拟航空警示灯
- **相机**：PerspectiveCamera，初始视角侧方 45° 俯瞰，FOV 50°，近裁面 1 远裁面 5000
- **交互**：OrbitControls 旋转/缩放/平移，点击吊索高亮并显示详情面板
- **后处理**：Bloom 发光效果作用于预警吊索，增强视觉冲击
- **性能预算**：吊索数量 ≤ 80，三角面总数 ≤ 200K，保持 60fps 渲染

## 5. 悬链线方程约束

主缆与吊索交点必须严格满足悬链线方程：

```
y = a * cosh(x / a) - a
```

其中 `a` 为悬链线参数（= 水平张力 / 均布荷载），由主缆跨度与垂度反算得出。吊索长度 = 主缆 y 坐标 - 桥面 y 坐标，确保几何一致。

## 6. ShaderMaterial 张力色谱规范

- **Uniform 变量**：`uTensionRatio`（float，0.0=安全/冷绿，1.0=预警/亮红）
- **顶点着色器**：传递归一化高度与实例化属性
- **片元着色器**：基于 `uTensionRatio` 在冷绿 `vec3(0.0, 1.0, 0.53)` 与亮红 `vec3(1.0, 0.2, 0.27)` 间平滑插值，加入微弱脉冲动画增强预警感知
- **色谱过渡**：0.0→0.3 冷绿，0.3→0.6 绿→黄渐变，0.6→1.0 黄→亮红
